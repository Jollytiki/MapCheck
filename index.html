Text / CSV Import File Formats

Overview

You can import traverses using standard .MAP files or custom plain text files (.txt or CSV). Comment lines beginning with # or // are ignored.

1. Straight Line Courses

Format: Course#, Bearing, Distance

1, N 45.3015 E, 150.25
2, 145.3015, 125.50
  • Bearing Format: Explicit quadrant (e.g. N 45.3015 E, S 89-30-00 W) or shorthand code (e.g. 145.3015, where the first digit 1-4 designates the quadrant: 1=NE, 2=SE, 3=SW, 4=NW, followed by DD.MMSS or DD-MM-SS).
  • Distance: Straight-line length in feet or meters.

2. Circular Curve Courses

Format: Course#, [Chord Bearing], C, TurnDirection, Parameter1, Parameter2

# Curve with explicit chord bearing (prefixed with CB):
3, CBN 45-00-00 E, C, R500, LA157.08
# Tangent curve (chord bearing is automatically calculated from previous course tangent):
4, C, R300, RA120.00
  • Chord Bearing (Optional): Prefixed with CB (e.g. CBN 45.0000 E). If omitted, the curve starts tangent to the preceding course.
  • Curve Indicator: C specifies this course is a circular curve.
  • Turn Direction & Arc Length: Use LA for Turn Left or RA for Turn Right, followed immediately by the arc length (e.g. LA157.08). Alternatively, specify turn direction as a standalone parameter L or R.
  • Curve Parameters (Provide exactly two of the following to resolve geometry):
    • R[value] — Radius (e.g. R500)
    • LA[value] / RA[value] — Arc Length (e.g. LA157.08)
    • CH[value] / CD[value] / CL[value] — Chord Length (e.g. CH120)
    • D[value] — Delta Angle in DD.MMSS format (e.g. D17.1122 for 17°11'22")

Command Summary

  • # – Comment line (ignored)
  • // – Comment line (ignored)
  • Course#, Bearing, Distance – Straight line course
  • Course#, C, R..., LA... – Circular curve with radius and arc length
  • CBN 45-00-00 E – Optional chord bearing for curve
  • R[value] – Radius
  • LA[value] / RA[value] – Arc length (Left/Right)
  • CH[value] / CD[value] / CL[value] – Chord length
  • D[value] – Delta angle (DD.MMSS)
